# Portfolio Demo

👉 Overview

This is a basic static portfolio website built with HTML and CSS. It is designed to present personal information such as resume details, skills, services offered, and project previews in a clean layout. The site includes fixed content and simple navigation for demonstration or learning purposes.

👉 Features

 • Multi-section layout: Home, About, Resume, Skills, Services, Portfolio, and Contact
 
 • Static HTML content with CSS styling
 
 • Font Awesome integration for icons
 
 • Contact form (non-functional placeholder)
 
 • Responsive design for basic screen sizes

 👉 Technologies Used
 
  • HTML5
 
  • CSS3
 
  • Font Awesome (via CDN).
